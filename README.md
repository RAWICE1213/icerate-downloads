# icerate 下载

icerate Windows x64 主程序与按需安装的附加组件。

## 下载与使用

1. 在右侧 Releases 下载 `icerate-0.9.24-Windows-x64.zip`。
2. 完整解压后运行 `icerate.exe`。
3. 使用高斯生成或胶片配方重算时，在「偏好设置 → 附加组件」安装所需组件。

主程序约246MB。普通渲染、导入已有高斯、使用已有胶片色表不需要安装附加计算环境。

## 附加组件

- **胶片配方计算器**：修改配方后重新计算色表。
- **高斯计算环境**：单图生成与多图训练。
- **MoGe模型**：默认从原作者固定版本地址下载。

附加包内提供独立运行环境，不要求安装Python或开发编译器。当前高斯训练预编译扩展面向NVIDIA计算能力8.6/8.9（RTX30/40），实测设备为RTX4070Ti；其他GPU未验收。

此仓库用于分发下载包和使用说明。随附第三方组件保留各自许可证和源码材料，详见包内说明；胶片计算工具的GPL-3.0源码包含于其独立附加包。
