# icerate

**交互式渲染、三渲二与二维分镜。**

icerate 是一款 Windows 图像创作工具，把场景布置、材质、灯光、摄像机和图像处理放在同一个工作流里。可以用路径追踪制作写实画面，也可以在分层渲染中尝试色块概括、描边和纸张质感，再通过二维工作区进行分镜绘制与画面加工。

## 可以做什么

- **场景与布光**：在 Layout 中摆放物体、调整灯光；点击物体表面定位高光，配合 HDR 环境、物理天空、黑旗和反光板塑造画面。
- **材质与渲染**：通过材质参数、贴图和程序化节点调整外观，选择分层渲染或 PT 路径追踪。
- **三渲二风格化**：控制明暗分区、形状概括、轮廓描边和纸张纹理；分别调整随位置变化的形状扰动与逐帧笔触。
- **摄像机与动画**：设置机位、景深和摄像机动画，预览导入的几何动画与 Alembic 缓存。
- **二维分镜**：绘制草图、调整画面时长、查看洋葱皮；将分镜叠加到 3D 视口作为构图参考，或把渲染结果送到 2D 场景继续绘制。
- **图像处理**：调节色彩、镜头光效、胶片风格与大气透视，用快照画廊保存不同方案并进行对比。
- **高斯与体积**：导入已有高斯场景和 VDB 体积；需要从图片生成高斯时，再安装对应的计算组件。

## 下载与安装

当前版本：**0.9.24 · Windows x64**。

1. 下载 [icerate-0.9.24-Windows-x64.zip](https://github.com/RAWICE1213/icerate-downloads/releases/download/v0.9.24/icerate-0.9.24-Windows-x64.zip)（约 246 MB）。
2. 将整个压缩包解压到一个文件夹。
3. 在该文件夹中运行 `icerate.exe`。

主程序无需安装编译工具。请保留解压后的目录结构，不要只拷贝 EXE。下载页的 **Source code** 是本仓库的文档归档，软件请下载上述 Windows ZIP。

## 快速开始

### 制作一张 3D 画面

1. **布置场景**：进入「3D 场景」，导入模型，在 Layout 中调整摆放与构图。
2. **设置外观**：选中对象编辑材质，添加灯光或环境；需要定向布光时，选中灯光后使用「布光」点击物体表面。
3. **选择画面风格**：简易着色适合摆放和查看场景；分层渲染适合调整风格化效果；PT 用于观察反射、折射等光照关系。
4. **完成图像**：在「图像」中调整色彩和后期效果。启用摄像机时，使用该摄像机的图像设置。
5. **对比与输出**：用快照保存方案，在画廊中切换、对比；在渲染设置中选择画幅和帧范围，输出单张图像或序列帧。

### 绘制分镜与再加工

切换到「2D 场景」，新建画面后绘制草图，在时间轴上调整持续帧数。洋葱皮用于参考前后画面，二维摄像机用于设计平移和缩放。

启用「发送至3D」后，分镜会成为 3D 场景中的参考层。也可以从 3D 渲染结果发送到 2D 场景，以渲染画面为底图继续绘制。

## 附加组件

普通渲染、导入已有高斯文件、使用已有胶片预设都可以直接使用主程序。以下组件仅在需要相应计算功能时安装：

| 组件 | 用途 | 下载量 |
| --- | --- | --- |
| 胶片配方计算器 | 修改胶片配方后重新生成色表 | 约 223 MB |
| 高斯计算环境 | 从单张图片生成高斯，或进行多图训练 | 约 3.01 GB |
| MoGe 模型 | 单图生成所需的深度与法线估计模型 | 约 1.32 GB |

打开 **偏好设置 → 附加组件**，选择安装位置，再点「下载安装」。组件自带所需运行环境，无需另外配置 Python。

需要离线安装时，从 [附加组件下载页](https://github.com/RAWICE1213/icerate-downloads/releases/tag/components-1.0.0) 下载相应文件，在软件中选择「从离线包安装」。高斯计算环境包含五个分包，需要全部下载并保留原文件名。

## 使用说明

[阅读 0.9.24 完整使用指南](https://github.com/RAWICE1213/icerate-downloads/blob/main/icerate-0.9.24-guide.zh-CN.md)：包含工程导入、视口与 Layout、材质节点、灯光、摄像机、三渲二、Paint、二维分镜、后期、输出和按模式分类的快捷键。Markdown 文件也可在本版 Release 的 Assets 中单独下载。

- 渲染速度和可容纳的场景大小取决于显卡、显存、输出分辨率及材质复杂度。
- DLSS 光线重建需要兼容的 NVIDIA RTX 显卡。当前高斯训练组件面向 RTX 30 / 40 系列，其他显卡架构暂未提供对应的训练包。
- 胶片预设可以实时预览；修改配方后，需要等待后台重新计算色表。
